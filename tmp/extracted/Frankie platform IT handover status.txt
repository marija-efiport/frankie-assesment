Frankie platform

Frankie is run on top of Mindsmiths platform, stand-alone product that has ISO 27001 certificate. You can find all related documentation on this link: Frankie platform ISO documentation
There are 2 services that are custom-built for Frankie that should be migrated to FS:
Custom CRM service - Holds the data about Frankie users (students, alumni, staff, and others), events, and user conversations with Frankie
Bookstack - Service hosting Frankie's knowledge base documents
GitHub account will be provided once set up. Estimates for delivering this are still being created.
 

Custom CRM service
 
Technical description:

Custom CRM service is a Django application ( Python ) that implements the CRM functionalities to create and manage data, automate processes, and provide backend capabilities for the Frankie Dashboard ( Gabrijel defined it in the mail above ). It uses a PostgreSQL database as the core database for all the data and a Redis database for caching. Included is also a basic administration site that allows CRUD operations for easy management.

Bookstack

Description:

BookStack is a simple, self-hosted, easy-to-use platform for organising and storing information. It provides a gold standard for Frankie's knowledge base. This is an open-source project used by many in production. Check more here: https://www.bookstackapp.com/ The application uses MariaDB as the main and only database.

Stack:

bookstack == 24.05.4 MariaDB == 20.1.1

Build and Deployment

We deploy BookStack using the Helm chart https://charts.gabe565.com/charts/bookstack/ . There are many other official options on how to install and deploy it: https://www.bookstackapp.com/docs/admin/installation/#docker

Server requirements:

vCPU: minimum 2, recommended 4
Memory: minimum 8 GB, recommended 16 GB
CPU Architecture: Intel Xeon or better
